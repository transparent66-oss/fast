# WHITE HOUSE presents「コーティング選びの正解」

スマートフォン・PCのブラウザーで遊べる、全10問の4択クイズです。回答ごとのフィードバックと解説、10点満点のスコア、4段階の結果ランク、回答傾向を表示します。

## ローカルで遊ぶ

`index.html` をブラウザーで開くだけで動作します。ビルドやパッケージのインストールは不要です。Google Fontsが使えない環境では、システムフォントに切り替わります。

## GitHub Pagesで無料公開

1. このフォルダーのファイルをGitHubの新しいリポジトリに追加します。
2. GitHubでリポジトリを開き、**Settings → Pages** に進みます。
3. **Build and deployment** の Source で **Deploy from a branch** を選びます。
4. 公開するブランチ（通常は `main`）、フォルダーは **/(root)** を選び、保存します。
5. Pagesの設定画面に表示されるURLを開いて確認します。公開反映には数分かかる場合があります。

GitHub Pagesは静的ファイルを配信するため、追加のサーバーやビルド工程は必要ありません。

## 問題の編集

問題文、選択肢、正解、回答別のフィードバックと解説は `questions.js` にあります。画面表示・進行・採点は `app.js`、見た目は `styles.css` が担当します。問題データの `answer` は選択肢の0始まりの番号です。

## 公開前の内容確認

解説は一般的な選び方を学ぶための内容で、特定の販売店・チェーン・ブランドを一律に評価しない設計です。製品ごとの性能、試験値、保証条件、推奨メンテナンスに関する主張を公開時に載せる場合は、必ず最新のメーカー資料・試験資料・保証書などで確認してください。車両、塗装状態、施工条件、使用環境によって結果は異なります。
