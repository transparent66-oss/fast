# HENRY DETAILING MASTER

ブラウザで遊べるディテーリング・アクションゲームのフェーズ1プロトタイプです。HTML5 Canvas と素の JavaScript で動作し、ビルド工程や外部ライブラリは必要ありません。

## 起動

`index.html` をブラウザで開きます。画面を押している間は上昇し、離すと下降します。PCではスペースキーでも操作できます。

## GitHub Pagesで公開

1. このフォルダー内のファイルをGitHubリポジトリのルートにアップロードします。
2. GitHubで **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、公開するブランチ（通常は `main`）と **/(root)** を指定して保存します。
4. 数分後に表示されるPagesのURLからアクセスします。

## ファイル

- `index.html` — 画面構成、タイトル、遊び方、リザルト
- `style.css` — レスポンシブな画面デザイン
- `game.js` — Canvas描画、操作、障害物、スコア、品質ゲージ
- `.nojekyll` — GitHub Pagesで静的ファイルをそのまま配信
- `.gitignore` — OS・エディターの一時ファイルを除外

## ゲーム内容

- タップ／長押しで研磨機を上下操作
- 障害物、グロスポイント、コンボ、ライフ
- 圧力・熱負荷の管理
- ランク付きリザルトと端末内ベストスコア保存
- スマートフォン・PC対応

本作は遊びやすさを優先したプロトタイプであり、実際の研磨工程を正確に再現するシミュレーターではありません。
