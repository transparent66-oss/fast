# HENRY GAMES

GitHub Pagesで公開できるゲーム一覧ページです。スマートフォンでの閲覧を優先した日本語デザインで、ゲームは独立したフォルダーに配置します。

## GitHub Pagesで公開

1. このフォルダー内のファイルとフォルダーをGitHubリポジトリのルートへアップロードします。
2. **Settings → Pages → Deploy from a branch** を開き、`main` ブランチと `/(root)` を選びます。
3. 発行されたURLを開きます。

## ゲームを追加・差し替え

ゲーム本体を `games/ゲーム名/` に配置し、ルートの `index.html` にあるカードのリンク、タイトル、説明文を更新してください。2本目は外部サイトへのリンクとして掲載しています。

- `games/detailing-master/` — HENRY DETAILING MASTER
- 外部リンク — コーティング選びの正解（https://transparent66-oss.github.io/fast/）
